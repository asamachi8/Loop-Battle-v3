# 公開手順（GitHub Pages）

オンライン対戦は、相手がURLを開ける状態になっている必要があります。
`index.html` をダブルクリックして開いた `file:///C:/Users/...` のURLは相手のPCでは開けないため、
GitHub Pages で公開してください。

このゲームは**静的ファイルだけ**でできているので、サーバーの用意もビルド作業も不要です。
ファイルをそのまま置くだけで動きます。Gitコマンドも使わず、ブラウザだけで完結します。

---

## 公開する

1. GitHub で新しいリポジトリを作成する（例：`loop-battle`）
   - **Public** にしてください（無料アカウントでは Private だと Pages を使えません）
2. `Add file → Upload files` を開き、フォルダの**中身をすべて**ドラッグ＆ドロップして
   `Commit changes`
   - `index.html` がリポジトリの**一番上**に来るようにしてください
   - `src/vendor/peerjs.min.js` を含め忘れないでください（オンライン対戦で必要です）
3. `Settings → Pages` を開く
   - **Source**：`Deploy from a branch`
   - **Branch**：`main` / `/ (root)` → `Save`
4. 1〜2分待つと `https://ユーザー名.github.io/リポジトリ名/` で公開されます

## 更新する

同じリポジトリで `Add file → Upload files` から変更したファイルを上げ直すか、
Git を使っているなら `git push` するだけです。数十秒〜数分で反映されます。

### ⚠️ CSS・JS を変えたときは番号を1つ上げる

GitHub Pages は `src/*.js` と `src/style.css` をブラウザにキャッシュさせます。
そのため **HTML だけ新しくなって、JS が古いまま**という状態が起こり、
「新しい枠は出るのに中身が空」といった中途半端な壊れ方をします。

これを防ぐため、`index.html` の読み込みタグに `?v=1.0.0` を付けてあります。

```html
<link rel="stylesheet" href="src/style.css?v=1.0.0">
<script src="src/config.js?v=1.0.0"></script>
…（9ファイルすべてに付いています）
```

**`src/` の中身を変えて公開するときは、この数字をすべて同じ値に上げてください**
（`1.0.0` → `1.0.1` など）。数字が変わるとブラウザは別のファイルとして読み直すので、
古いキャッシュが使われなくなります。

それでも反映されないときは `Ctrl + Shift + R`（強制再読み込み）を試してください。

## アップロードするもの

**Ver.1.0 から、アップロード用のフォルダを用意しています：**
`Cowork\ループバトル\Loop Battle Ver1.0 GitHubアップロード用`

このフォルダを開き、**中身をすべて選んで**（Ctrl+A）GitHub の `Upload files` の画面へドラッグしてください。
フォルダそのものではなく「中身」を入れるのがポイントです（`index.html` がリポジトリの一番上に来るように）。

アップロード用フォルダには、次のものを**入れていません**（ゲームは読み込まないため）：

- 駒の元画像 `assets/pieces/*/original/`（約16MB）
- アイコンの元画像 `assets/icons/original/`
- 空の置き場 `assets/ui/`・`assets/reference/`、`.gitignore`

素材の元データは `Cowork\ループバトル\控え素材（ループバトル関係）` に保管しています。

中身は次のとおりです。

```
index.html          ← これがトップページになる
manifest.webmanifest ← ホーム画面・ショートカットの名前とアイコンの設定
src/                ← ゲーム本体（vendor/peerjs.min.js も必要）
assets/             ← 画像（額縁・駒）と戦闘BGM（bgm/ に mp3 が3曲・計約10MB）
docs/               ← 入れなくても動作しますが、入れて問題ありません
README.md
LICENSE
.nojekyll           ← GitHub Pages が余計な処理をしないようにするための空ファイル
```

`src/vendor/peerjs.min.js` はオンライン対戦の接続に使うため、**必ず含めてください**。
これが無いとオンライン対戦を開始したときに読み込みエラーになります。

`assets/icons/` と `manifest.webmanifest` を入れ忘れると、ショートカットのアイコンが出ません（ゲームは動きます）。
`assets/bgm/` の mp3（3曲）も含めてください。無いと戦闘BGMだけが鳴らなくなります（ゲームは動きます）。
GitHub のブラウザからのアップロードは1ファイル25MBまでなので、1曲3〜4MBなら問題ありません。

`assets/reference/`（デザインの参考画像）に他者の著作物を入れている場合は、
公開リポジトリへ上げないでください。詳しくは `assets/README.md` を参照。

## 公開後の対戦手順

1. 公開したURLを開く
2. **先攻（青）／後攻（赤）／ランダム** から自分の担当を選ぶ（部屋を作る側が決められます）
3. **対戦部屋を作る** を押す
4. 表示された `?room=XXXXXX` 付きのURLをコピーして相手に送る
   - `コピー` のほか、**LINE / X / メール / 端末の共有メニュー**のボタンがあります
   - 共有ボタンはすべて新しいタブで開くので、対戦ページは閉じずにそのまま使えます
5. 相手がそのURLを開くと接続され、対戦が始まる

対局中はブラウザを開いたままにしてください。
閉じてしまった場合でも、同じ部屋URLを開き直せば途中から復帰できます
（部屋を作った側のブラウザが開いている間に限ります）。

## うまく繋がらないとき

| 症状 | 原因と対処 |
| --- | --- |
| 「オンライン対戦は公開したURL上でのみ使えます」と出る | `file://` で開いています。公開したURLを使ってください |
| 「通信ライブラリを読み込めませんでした」 | `src/vendor/peerjs.min.js` がアップロードされていません |
| 「相手が見つかりません」 | 部屋を作った側がページを閉じています。作り直して新しいURLを送ってください |
| 「仲介サーバーに接続できませんでした」 | 接続の仲介に使う外部サービスが一時的に落ちている可能性があります。時間をおいてください |
| 「相手のバージョンが違います」 | 片方が古い版を開いています。両者とも強制再読み込みしてください |
| 対局中に盤面がズレた | 「盤面を最新に更新」ボタンを押すと揃え直せます |
| つながらない／途中で切れる | 会社や学校のネットワーク、一部のモバイル回線では P2P 通信が遮断されることがあります。別の回線で試してください |

接続の仲介には PeerJS の公開ブローカーを使っています。
安定させたい場合は自前の PeerServer を立て、`src/online.js` の `new Peer()` に
`host` / `port` / `path` オプションを渡すよう変更してください。
