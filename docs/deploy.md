# 公開手順（オンライン対戦を使うために）

オンライン対戦は、相手がURLを開ける状態になっている必要があります。
`index.html` をダブルクリックして開いた `file:///C:/Users/...` のURLは相手のPCでは開けないため、
どこかに公開（ホスティング）してください。

このゲームは**静的ファイルだけ**でできているので、サーバーの用意やビルド作業は不要です。
フォルダをそのままアップロードするだけで動きます。

---

## Netlify Drop（最短・アカウント登録は後からでOK）

1. https://app.netlify.com/drop をブラウザで開く
2. `loop-battle` フォルダ**ごと**、ページ上の点線枠へドラッグ＆ドロップする
3. アップロードが終わると `https://ランダムな名前.netlify.app` が発行される
4. そのURLを開いて動作を確認する
5. URLを覚えやすくしたい場合は、Netlify にログインして
   `Site configuration → Change site name` から名前を変更する

> アカウントを作らずに公開した場合、サイトは一時的なものとして扱われます。
> 継続して使うなら無料アカウントを作成して「Claim」しておいてください。

### 更新するとき

同じ手順でフォルダを再度ドロップするか、Netlify のサイト画面の
`Deploys → Deploy manually` へドラッグ＆ドロップします。

---

## GitHub Pages（リポジトリとして公開する場合）

Gitコマンドは不要で、ブラウザだけで完結します。

1. GitHub で新しいリポジトリを作成する（例：`loop-battle`）
   - **Public** にしてください（無料アカウントでは Private だと Pages を使えません）
2. `Add file → Upload files` を開き、フォルダの**中身をすべて**ドラッグ＆ドロップして
   `Commit changes`
   - `index.html` がリポジトリの一番上に来るようにしてください
   - `src/vendor/peerjs.min.js` を含め忘れないでください
3. `Settings → Pages` を開く
   - **Source**：`Deploy from a branch`
   - **Branch**：`main` / `/ (root)` → `Save`
4. 1〜2分待つと `https://ユーザー名.github.io/リポジトリ名/` で公開されます

### 更新するとき

同じリポジトリで `Add file → Upload files` から変更したファイルを上げ直すか、
Git を使っているなら `git push` するだけです。数十秒〜数分で反映されます。

---

## Cloudflare Pages

1. Cloudflare アカウントを作成してログイン
2. `Workers & Pages → Create → Pages → Upload assets` を選ぶ
3. プロジェクト名を入力し、`loop-battle` フォルダをドラッグ＆ドロップ
4. `Deploy site` を押すと `https://プロジェクト名.pages.dev` が発行される

### 更新するとき

同じプロジェクトの `Create new deployment` からフォルダを再アップロードします。

---

## アップロードするもの

フォルダの中身をそのまま入れてください。除外するファイルはありません。

```
index.html          ← これがトップページになる
src/                ← ゲーム本体（vendor/peerjs.min.js も必要）
docs/               ← 入れなくても動作しますが、入れて問題ありません
README.md
```

`src/vendor/peerjs.min.js` はオンライン対戦の接続に使うため、**必ず含めてください**。
これが無いとオンライン対戦を開始したときに読み込みエラーになります。

---

## 公開後の対戦手順

1. 公開したURLを開く
2. 右側の「オンライン対戦」で **対戦部屋を作る** を押す
3. 表示された `?room=XXXXXX` 付きのURLをコピーして相手に送る
4. 相手がそのURLを開くと接続され、対戦が始まる
5. 部屋を作った側が Player 1（青・先手）、参加した側が Player 2（赤）

対局中はブラウザを開いたままにしてください。
閉じてしまった場合でも、同じ部屋URLを開き直せば途中から復帰できます
（部屋を作った側のブラウザが開いている間に限ります）。

---

## うまく繋がらないとき

| 症状 | 原因と対処 |
| --- | --- |
| 「オンライン対戦は公開したURL上でのみ使えます」と出る | `file://` で開いています。公開したURLを使ってください |
| 「通信ライブラリを読み込めませんでした」 | `src/vendor/peerjs.min.js` がアップロードされていません |
| 「相手が見つかりません」 | 部屋を作った側がページを閉じています。作り直して新しいURLを送ってください |
| 「仲介サーバーに接続できませんでした」 | 接続の仲介に使う外部サービスが一時的に落ちている可能性があります。時間をおいてください |
| つながらない／途中で切れる | 会社や学校のネットワーク、一部のモバイル回線では P2P 通信が遮断されることがあります。別の回線で試してください |

接続の仲介には PeerJS の公開ブローカーを使っています。
安定させたい場合は自前の PeerServer を立て、`src/online.js` の `new Peer()` に
`host` / `port` / `path` オプションを渡すよう変更してください。
