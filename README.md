# Loop Battle

**3騎 VS 3騎 ループ戦術ボードゲーム** — Ver.0.4（開発中）

Surakarta（スラカルタ）型の「通常経路＋ループ経路」を持つ盤面から着想を得た、
オリジナル戦術ボードゲームのゲーム性検証用プロトタイプです。

同じPCで2人対戦、または**URLを共有して離れた相手とオンライン対戦**ができます。

> 完成品ではなく、**「6駒だけで、ループを利用した位置取りと突撃が面白いか」**
> を実際にプレイして判断するためのものです。

**▶ プレイする：** `（GitHub Pages で公開したらここにURLを書く）`

---

## 特徴

- **HTML + CSS + JavaScript のみ。** ビルド作業もパッケージのインストールも不要
- ファイルをそのまま置くだけで動くので、**GitHub Pages にアップロードすれば即プレイ可能**
- ローカルでは `index.html` をダブルクリックするだけで動作
- 盤面のループ配置を **3種類** から切り替えて比較できる
- 戦闘ログの枠を**盤面の左右どちらにも配置**でき、位置は次回起動時も保持される
- HP・ダメージ・ノックバックなどの数値を**画面上から変更**して即テストできる

---

## ゲーム概要

- 6×6 の**交点盤**。駒はマスの中ではなく、線と線が交わる交点に置きます。
- 盤の隅には**ループ弧**があり、線の端どうしを繋いでいます。弧の配置が異なる3種類の盤面を切り替えられます。

  | 種類 | 名称 | 弧 | 経路の性質 | ループ入口 |
  | --- | --- | --- | --- | --- |
  | 1（既定） | 全隅ダブルループ | 8本 | 一周する回路が2つ（各24歩） | 16地点 |
  | 2 | 対角2ループ | 2本 | 一周せず行き止まり（6交点） | 4地点：`4 13 24 33` |
  | 3 | 右上・左下ダブルループ | 4本 | 4本とも行き止まり（各6交点） | 8地点：`3 5 12 18 19 25 32 34` |

- **ループ入口**（薄い丸で表示）に立っているときだけ、ループ突撃を開始できます。
- Player 1（青・下側）と Player 2（赤・上側）が3騎ずつ持ち、交互に1騎だけ行動します。
- **通常移動**は1マスだけ。**ループ突撃**はループを通れば盤の反対側まで一気に届きます。
- 相手の3騎をすべて撃破したプレイヤーの勝利（仮の勝利条件）。

## ルール

| 項目 | 内容 |
| --- | --- |
| 騎の数 | 各プレイヤー3騎（性能は全騎共通） |
| 最大HP | 5 |
| 通常移動 | 縦横に隣接する**空き交点**へ1マス。駒の飛び越し不可。ループ弧は使わない |
| 通常接近攻撃 | 移動によって**新しく隣接した**敵全員へ 1 ダメージ |
| ループ突撃の条件 | **ループ入口に立っていること**。加えて、経路上に他の駒が無いこと |
| ループ突撃 | ループ弧を通って、最初にぶつかった敵まで一気に突撃して 3 ダメージ |
| ノックバック | 生存した対象を突撃してきた向きへ 1 マス押し出す。**後ろに駒があればその駒ごと押し出す** |
| 壁激突 | 押し出される列の先が盤端で詰まっている場合は押し出さず、代わりに追加 1 ダメージ（合計 4） |
| 突撃後の位置 | 撃破または押し出せた場合＝対象がいた交点へ／押し出せなかった場合＝対象の1つ手前で停止 |
| 撃破 | HP0 で盤面から除去（復活なし） |
| 勝利条件 | 相手の3騎をすべて撃破する（仮仕様） |

## 遊び方

### 同じPCで2人対戦

1. `index.html` をダブルクリックしてブラウザで開く
2. 交互に操作する

### オンライン対戦（離れた相手と1対1）

1. 公開したURL（`https://ユーザー名.github.io/リポジトリ名/`）を開く
2. **先攻（青）／後攻（赤）／ランダム** から自分の担当を選ぶ（部屋を作る側が決められます）
3. **対戦部屋を作る** を押す
4. 表示されたURLを相手に送る
   - `コピー` のほか、**LINE / X / メール / 端末の共有メニュー**のボタンがあります
   - 共有ボタンはすべて新しいタブで開くので、**この対戦ページは閉じずにそのまま使えます**
5. 相手がURLを開くと接続され、対戦開始

対戦中の画面：

- **盤面左の手番表示**で、今どちらの番か・それが自分か相手かが分かります（自分の番は枠が光ります）
- 自分の手番以外は盤面を操作できません
- **盤面を最新に更新**：通信が一瞬途切れたときに押すと、双方の盤面を揃え直せます
- **降参する**：手詰まりのときに相手の勝ちとして対局を終えられます（確認が出ます）
- ルール設定・盤面の種類・RESTART は部屋主のみが操作でき、変更は相手にも反映されます
- 先攻・後攻を対局中に変えると、確認のうえ対局を最初からやり直します
- ブラウザを閉じても、同じURLを開き直せば途中から復帰できます

対局データは2台のブラウザ間で直接やり取りされます（WebRTC / P2P）。
接続の確立にのみ外部の仲介サービスを使い、対局内容はサーバーを経由しません。

### 操作方法

1. **自軍の騎をクリック**して選択
   - 白い破線リング＝選択中／緑の丸＝移動できる交点／黄色の破線リング＝ループ突撃できる敵
   - ループ弧の上の**小さな▲**＝その騎がループを使うときに進む向き
2. **緑の丸をクリック** → 通常移動（新しく隣接した敵に自動で -1）
3. **黄色いリングの敵にカーソルを合わせる** → 突撃経路がハイライト表示
   - 騎を選んだ時点で、ループ弧の上に**進む向きの小さな▲**が出ます（どちら回りに抜けるかの目印）
4. **その敵をクリック** → ループ突撃（-3）
   - 同じ敵へ複数の経路がある場合は経路の1歩目に **①②** のバッジが出ます
5. Esc または別の騎をクリックで選択し直し
6. `降参する` で手詰まりのときに対局を終了（確認あり）
7. `座標を隠す` ボタンで交点番号の透かしを切り替え／`RESTART` でいつでも初期化
8. 「ログ / リプレイ」で直近3対局を再生・停止して振り返れる
9. ログ枠の `◀ 左へ` / `右へ ▶` ボタンで、ログを盤面の左・右どちらにも置ける（位置は次回も保持）

## リプレイ（直近3対局を振り返る）

サイドパネルの「ログ / リプレイ」から、対局を後で見返せます。

1. プルダウンで対局を選ぶ（`現在の対局` と、終わった直近3対局。勝敗と手数が出ます）
2. `▶ 再生` で 0.7 秒ごとに1手ずつ進む（再生中は `⏸ 一時停止`）
3. `◀` `▶|` で1コマずつ戻す・進める
4. `■ 停止` で進行中の対局に戻る

再生中は盤面・ログ・手番表示・HP がその時点の内容になり、盤面の枠が紫色になります。
リプレイ中は盤面を操作できません。戦歴は最大3対局まで、ページを開いている間だけ保持されます。

ログ枠は見出しのボタンで**盤面の左**にも移せます。左に置くとログが縦に長く表示され、
盤面と並べて追いやすくなります。選んだ位置はブラウザに保存され、次に開いたときも同じ配置になります。

## GitHub Pages で公開する

Gitコマンドは不要です。ブラウザだけで完結します。

1. GitHub で新しいリポジトリを作成する（例：`loop-battle`）
   - **Public** にしてください（無料アカウントでは Private だと Pages を使えません）
2. リポジトリの `Add file → Upload files` を開き、**このフォルダの中身をすべて**
   ドラッグ＆ドロップして `Commit changes`
   - `index.html` がリポジトリの**一番上**に来るようにしてください
   - `src/vendor/peerjs.min.js` を含め忘れないでください（オンライン対戦で必要です）
3. `Settings → Pages` を開く
   - **Source** を `Deploy from a branch`
   - **Branch** を `main` / `/ (root)` にして `Save`
4. 1〜2分待つと `https://ユーザー名.github.io/リポジトリ名/` で公開されます
5. そのURLを開いて「対戦部屋を作る」→ 出てきたURLを相手に送れば対戦できます

公開後は、このREADMEの冒頭「▶ プレイする」にURLを書いておくと便利です。

アップロードするファイルの詳細や、繋がらないときの対処は [`docs/deploy.md`](docs/deploy.md) にあります。

## 数値の調整

ゲームバランス用の数値は本体コードから分離しています。

- **一時的に変える**：画面右の「デバッグ設定」で変更 →「適用してリスタート」
  （`HP 5 で開始` / `HP 6 で開始` のワンクリック比較、盤面の種類の切り替えもここ）
- **恒久的に変える**：[`src/config.js`](src/config.js) を編集

```js
MAX_HP: 5,
NORMAL_DAMAGE: 1,
LOOP_DAMAGE: 3,
KNOCKBACK_DISTANCE: 1,
WALL_DAMAGE: 1,          // 盤端で押し出せない場合の追加ダメージ
CHAIN_KNOCKBACK: true,   // 後ろの駒ごと押し出すか
BOARD_TYPE: 1,           // 盤面の種類（1=全隅ダブル / 2=対角2ループ / 3=右上・左下ダブル）
LOOP_ENTRY_MAX_STEPS: 1, // 1 = ループ入口に立つ必要あり / 99 = Ver.0.1 の挙動
INITIAL_PLACEMENT: { p1: [26, 27, 28], p2: [9, 10, 11] }  // 盤面のマス番号
```

盤面の種類を増やす場合は `src/config.js` の `LB.BOARD_TYPES` に1件追加するだけです。
弧は盤面に表示されている通し番号のペアで書けます（例：`arcs: [[4, 24], [13, 33]]`）。

## プロジェクト構成

```
.
├── index.html              エントリポイント（これを開けば起動）
├── README.md               このファイル
├── LICENSE                 ライセンス
├── docs/
│   ├── specification_v0.3.md   Ver.0.3 正式仕様書（最新）
│   ├── specification_v0.2.md   Ver.0.2 仕様書（履歴）
│   ├── specification_v0.1.md   Ver.0.1 仕様書（履歴）
│   ├── deploy.md               GitHub Pages への公開手順とトラブル対処
│   └── changelog.md            バージョンごとの変更履歴
└── src/
    ├── config.js           調整用の数値・盤面の種類・初期配置
    ├── board.js            盤面ジオメトリ／ループ弧／経路の1ステップ移動
    ├── rules.js            ルール判定（移動・接近攻撃・ループ突撃・ノックバック・撃破・勝利）
    ├── game.js             ゲーム状態とターン管理
    ├── ui.js               描画と入力処理
    ├── net.js              オンライン対戦の同期処理（通信手段に依存しない）
    ├── online.js           WebRTC の接続と対戦部屋のURL
    ├── main.js             起動処理・デバッグ設定パネル
    ├── style.css           スタイル
    └── vendor/
        └── peerjs.min.js   通信ライブラリ（オンライン対戦時のみ読み込む）
```

### 設計方針

- **ゲームロジックとUIを分離。** `rules.js` は DOM を一切参照せず、処理結果を
  イベント配列（`move` / `damage` / `knockback` / `ko`）で返し、見せ方は `ui.js` の責任。
- ループ経路の判定は `board.js`（幾何）と `rules.js`（成立条件）に閉じており、
  描画処理には埋め込まれていません。
- オンライン対戦の同期処理（`net.js`）は通信手段に依存しません。
  `send` と `onMessage` を持つオブジェクトを渡すだけで動くため、
  ループバック接続を使えばブラウザ1枚で同期処理をテストできます。
- 勝利判定は `rules.checkWinner()` の1関数のみ。到達勝利・拠点制圧などへ
  差し替える場合はここだけを変更します。

## 検証したいこと

1. ループ入口を確保する動きが駆け引きとして成立しているか
2. ループ入口の制限は厳しすぎないか
3. 連鎖押し出しと壁激突で、ノックバックが盤面を崩す手段になっているか
4. HP は 5 と 6 のどちらが適切か
5. 3騎という数は適切か
6. 全滅勝利は面白いか（単なる殴り合いになっていないか）
7. 決着までの手数が長くなりすぎていないか

詳細は [`docs/specification_v0.3.md`](docs/specification_v0.3.md) を参照してください。

## 既知の制限（オンライン対戦）

- 接続の仲介に PeerJS の公開ブローカーを使っているため、そのサービスが停止すると
  新規接続ができません（対局中の通信は影響を受けません）
- 会社・学校のネットワークや一部のモバイル回線では P2P 通信が遮断され、繋がらない場合があります
- 不正防止は行っていません。相手から送られてくる盤面をそのまま信頼します
- 観戦・再戦招待・レーティング・チャットは未実装です
